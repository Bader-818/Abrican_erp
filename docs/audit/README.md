# Abrican ERP — Testing & Consistency Audit

System-wide audit of logic correctness and cross-module consistency. Report-first:
discrepancies are catalogued, not silently fixed.

## Artifacts
- **[INVARIANTS.md](INVARIANTS.md)** — the canonical logic invariants per domain + the
  cross-module contracts. The oracle for tests and the manual checklist.
- **[FINDINGS.md](FINDINGS.md)** — the curated discrepancy register (the gate for any fix pass).
- **[CONSISTENCY-REPORT.md](CONSISTENCY-REPORT.md)** — auto-generated by the static checks.
- **[SMOKE-MATRIX.md](SMOKE-MATRIX.md)** — per-role manual verification checklist.

## How to run
```bash
# Static consistency checks (read-only; regenerates CONSISTENCY-REPORT.md)
cd backend && npm run audit:consistency

# Unit tests (mocked Prisma, no DB)
cd backend && npx jest

# End-to-end (needs the dev Postgres up; clears admin MFA first if needed)
cd backend && npm run test:e2e
```

The static checks live in `backend/scripts/audit/` (`rbac-triangle`, `enum-parity`,
`decimal-parity`, `pagination-guard`, `audit-coverage` + `run.mjs`).

The codebase is highly consistent, and **all findings are now resolved**. The static

issues — an orphan permission (F-001, removed) and a stale payment-response snapshot
